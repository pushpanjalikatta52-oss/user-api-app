# User API App

## 📌 Project Overview

The **User API App** is a simple React application that retrieves user information from an API and displays it in a clean table format. The project demonstrates how to use React **useState()**, **useEffect()**, and **fetch()** to work with API data.

## 🚀 Features

- Fetches user data from an API
- Displays User ID
- Displays Name
- Displays Username
- Displays Email
- Shows **Loading...** while fetching data
- Displays an error message if the API request fails
- Simple and responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Fetch API
- JSONPlaceholder API

## 🔗 API Used

`https://jsonplaceholder.typicode.com/users`

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:

```bash
npm install
```

4. Start the React application:

```bash
npm run dev
```

5. Open the application in your browser:

**http://localhost:5173/**

## 🎯 Learning Objective

This project helps beginners understand how React handles API requests using **useEffect()**, manages data using **useState()**, and retrieves information using the JavaScript **fetch()** method.
